# Exercise — cache a fact, or preserve a right?

Run the suite on CPython 3.12.14. Read the negative-control test without opening the solution.

1. Admit one intent at time 40; revoke it at time 45; execute at time 50 before its deadline.
2. Predict the balance of each consumer. Explain why unchanged message fields do not settle the authorization question.
3. In a disposable copy, replace CurrentConsumer's live wallet check with the CachedConsumer cache check. Which rejection test fails, and is the state still unchanged?
4. Add a test that revokes proof-A, grants proof-B for the same intent, rejects A and accepts B exactly once.

Explain it yourself: when should accepting an order create an irrevocable commitment? If that is your policy, where is the commitment represented and how can it be cancelled? The lab intentionally chooses revocable execution authority.
