# Security scope

This repository contains intentionally vulnerable educational code. Run it locally with synthetic inputs. It has no live deployment, wallet integration or financial execution interface.

Do not use the examples as production bridge or runtime components. Do not include secrets or private incident details in public issues. For a finding affecting another project, follow that project's disclosure process before posting technical details here.

For a defect in these toy models, provide a minimal offline test and explain the expected invariant. Clearly distinguish a flaw in an example from a vulnerability in a deployed protocol.
